# Donna's Garden 🌸

A living orchid tamagotchi with daily Notes from the Universe, made with love.

## Deploy to GitHub Pages

1. Create a new GitHub repo (e.g. `donnas-garden`)
2. Upload all files from this folder
3. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. GitHub will give you a URL like `https://yourusername.github.io/donnas-garden`
5. Send Donna that link!

## Add to Home Screen (iPhone)

1. Open the link in **Safari**
2. Tap the **Share** button (box with arrow)
3. Tap **"Add to Home Screen"**
4. Tap **Add**

It will appear as a full-screen app on her home screen 🌸

## Add to Home Screen (Android)

1. Open the link in **Chrome**
2. Tap the **three dots menu**
3. Tap **"Add to Home Screen"**
4. Tap **Add**
